Quick Start

Access the API with simple HTTPS requests. No authentication required.

# Get all courses for Fall 2025 fetch('https://jlumbroso.github.io/penn-path-scraper/api/v1/terms/202530/') .then(res => res.json()) .then(data => console.log(data)) # Get enrollment history for a specific course fetch('https://jlumbroso.github.io/penn-path-scraper/api/v1/courses/CIS-1210/enrollments.json') .then(res => res.json()) .then(data => console.log(data.enrollment_history))

API Endpoints

/api/v1/
Master API index with stats, available terms, and all course codes
/api/v1/courses/{course-code}/
Course metadata: sections, instructors, meetings, current enrollment
/api/v1/courses/{course-code}/enrollments.json
Time-series enrollment data with daily snapshots
/api/v1/terms/{term-code}/
All courses offered in a specific term
/api/v1/search/instructors.json
Instructor → courses mapping for all terms
/api/v1/search/departments.json
Department → courses mapping for all terms
