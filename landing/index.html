Quick Start

Access the API with simple HTTPS requests. No authentication required.

# Get all courses for Fall 2025 fetch('https://jlumbroso.github.io/penn-path-scraper/v1/terms/202530/index.json') .then(res => res.json()) .then(data => console.log(data)) # Get enrollment history for a specific course fetch('https://jlumbroso.github.io/penn-path-scraper/v1/courses/CIS-1210/enrollments.json') .then(res => res.json()) .then(data => console.log(data.enrollment_history))

API Endpoints

/v1/index.json
Master API index with stats and available endpoints
/v1/courses/{course-code}/index.json
Course metadata: sections, instructors, meetings, current enrollment
/v1/courses/{course-code}/enrollments.json
Time-series enrollment data with daily snapshots
/v1/terms/{term-code}/index.json
All courses offered in a specific term
/v1/search/instructors.json
Instructor → courses mapping for all terms
/v1/search/departments.json
Department → courses mapping for all terms
